УСТАНОВКА — ХОГВАРТС: ШЕСТОЙ КУРС

1. Распакуйте архив. Загрузите все файлы из папки app в одну папку HTTPS-сайта. Файлы manifest.webmanifest и sw.js должны открываться по URL без авторизации и перенаправления на HTML.
2. Импортируйте в n8n файлы «Sixth Year — Story.json» и «Sixth Year — Image.json». Настройте собственные учётные данные PostgreSQL, AI-модели и Polza, затем активируйте workflow.
3. В меню приложения укажите базовый URL n8n. Приложение использует вебхуки sixth-year-turn и sixth-year-image; для сайта на новом домене проверьте разрешённый Origin в n8n.
4. Откройте адрес папки на телефоне. Android: Chrome → меню → «Установить приложение». iPhone: Safari → «Поделиться» → «На экран Домой».
5. Запускайте с новой иконки: приложение откроется в отдельном окне без адресной строки.

Это устанавливаемое веб-приложение (PWA), не APK/IPA. Оболочка доступна после первого открытия и без сети. Для AI-истории и генерации иллюстраций интернет необходим.
Настройки подключения и идентификатор пользователя привязаны к домену. Не очищайте данные сайта, если хотите сохранить локальную историю и привязку к серверной сессии. Синхронизация между устройствами не добавлена.
